# xie-media

> 一条命令，把任意一个本地目录变成带账号体系的私人**流媒体**库。

`xie-media` 是一个 Node.js 命令行工具。你在终端敲一条命令、指定一个目录，它就会在这个目录上起一个 Web 服务——你可以注册账号、上传视频与图片、在浏览器里浏览与流畅播放、收藏喜欢的作品，还能把自己的作品"开放"到广场给其他用户看。

无需外部数据库，媒体文件与元数据（SQLite）都存在你指定的目录里。

---

## ✨ 特性

- **一条命令启动**：`xie-ms --dir /path/to/media`，零配置。
- **内置账号体系**：注册 / 登录 / 管理员后台开箱即用，首个注册用户自动成为管理员。
- **无类型资源集合**：不再区分"视频/相册"，一个资源就是若干文件的容器，图片与视频可任意混装；详情页根据内容自动选择浏览方式（全视频→播放器+列表自动连播；含图片→平铺网格），也可手动切换。
- **上传不再选模式**：一次拖入 N 个图片/视频文件即归为一个资源；提交前文件列表可**拖拽排序**（鼠标/触屏，顺序决定入库与封面）；带**总进度条 + 逐文件上传状态**，大文件不再看着像卡住。
- **批量模式**：勾选后每个文件单独成一个资源（如手机上拍的多段视频），逐个上传、每行显示各自进度；标题自动取各文件名，部分失败不影响其余。
- **批量自动入库（scan 目录）**：往工作目录下的 `scan/` 丢文件即可——服务每 10 秒扫描一次，散文件各自成一个资源、一级子文件夹整体成一个资源（标题取文件名/文件夹名），自动去重、默认私有、归属管理员。
- **详情页承载所有操作（分散式布局）**：卡片仅跳转；返回按钮在顶栏（菜单按钮旁），收藏是 meta 行末尾的心形图标、编辑信息是标题后的小铅笔图标，编辑文件 / 开放访问 / 删除排在文件列表上方操作条；权限不足自动隐藏。移动端列表为双列小卡：标题浮动叠在缩略图底部（白字 + 半透黑底），只显示标题，界面更紧凑。
- **线性 SVG 图标**：界面图标（编辑/收藏/可见性/删除/排序/视图切换/菜单/返回）统一 feather 风线性 SVG，stroke 跟随字色深浅自适应；收藏切换描边↔实心态；详情页列表模式选集项只显示文件名与时长。
- **文件维护**：详情页可**批量重命名 / 删除 / 拖拽把手排序（或上下移微调）/ 追加上传**，一次"保存"落库。
- **我的 / 广场 / 收藏**：三种视图；广场展示所有公开内容（含你自己开放的，方便验证效果）。
- **列表多选批量操作**：顶栏“选择”进入多选，可对选中资源一次执行**合并 / 公开 / 私有 / 送人 / 删除**（“广场”可批量收藏、“收藏”可批量取消收藏）。桌面端动作排在底部横栏；移动端一行装不下，改为**靠右浮动的竖向 dock**（纵向居中、顶部显示已选数量），作为浮层叠在列表上，不挤压列表宽度。
- **送人（转移所有权）**：把自己的资源送给另一个用户——`owner` 变更且**强制转为私有**，送出方不再拥有该资源（也不再保留它的收藏记录），磁盘文件不动（只换所属集合）。接收方在“我的”里看到它，可再次送出。
- **收藏**：一键收藏 / 取消收藏（幂等）。
- **可见性可控**：上传默认仅自己可见，手动"开放到广场"后才公开。
- **分类 + 搜索**：为资源打自定义分类标签，配合标题关键字快速检索。
- **缩略图懒生成**：首次访问视频时调用 `ffmpeg` 抽帧生成缩略图；集合封面自动取首项。
- **视频元数据自动提取**：上传时用 `ffprobe` 读取时长 / 分辨率 / 编码格式，卡片显示时长角标、详情页展示聚合信息与每条文件的元数据，一眼判断可否流畅播放。
- **无限滚动**：滚动到底自动加载下一页，每页 24 条。
- **流式播放**：文件按需流式传输，支持 Range 断点/拖动与浏览器 ETag 缓存。
- **移动端 · PC 双端**：全部页面响应式；移动端侧栏变汉堡抽屉、卡片单列、播放器上下堆叠。
- **文件去重**：媒体按 md5 存储，相同内容只占一份磁盘；删除按引用计数回收。
- **数据本地化**：媒体文件 + SQLite + 用户配置 全部落在你的目录内，随时拷走。

## 📦 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | ≥ 22.5 | 运行环境（内置 `node:sqlite`） |
| ffmpeg | 任意近期版本 | 视频封面抽帧 + 元数据读取（自带 `ffprobe`），**必需**；未安装服务启动会报错退出 |

安装 ffmpeg：

```bash
# Ubuntu / Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```

## ⚡️ 快速开始

```bash
# 在某个目录上启动媒体库（端口默认 3000）
xie-ms --dir ~/MyMedia

# 浏览器打开
http://localhost:3000
```

首次进入会跳转到登录页。**第一个注册的用户自动成为管理员**，登录后即可上传与管理。

启动成功后控制台会打印生效配置：

```
xie media server
  title : xie media server
  dir   : /home/you/MyMedia
  scan  : /home/you/MyMedia/scan
  port  : 3000
  ➜  http://localhost:3000
```

## 🧭 使用流程

1. **注册管理员**：首次访问跳转登录页 → 点"注册" → 首个账号即为管理员。
2. **上传媒体**：主页"我的"视图右上点"上传"：
   - 一次拖入 **任意多个图片 / 视频文件**（不再选类型），它们归为一个资源；可填写标题与分类。
   - 上传时底部显示**总进度条**，文件列表逐行显示状态（待上传 / 上传中 / 完成 / 失败）。
   - 提交前可**按住每行左侧把手拖动文件排序**（手机触屏同样可用），顺序决定入库次序与封面（首个文件）；开始上传后锁定。
   - 勾选**批量模式**时，每个文件单独成为一个资源逐个上传（标题自动取各文件名），每行显示该文件自己的进度；适合一次导入手机上拍的多段视频。
   - 上传成功后**默认仅自己可见**。
3. **浏览与播放**：
   - 左侧菜单切 **我的 / 广场 / 收藏**；搜索框按标题或分类过滤（不再有"全部/视频/相册"分类 tab）。
   - 列表滚动到底自动加载下一页。
   - **卡片没有操作按钮**，点击卡片进入**详情页**（浏览方式根据内容自动选定，可在列表/平铺间切换）：
     - 全视频：大播放器 + 播放列表；默认选中第一项并尝试自动播放（不默认静音，可能被浏览器拦截），播完自动接下一项；点列表切换。
     - 含图片：图 / 视频网格，点击进大图（键盘 ← →，或触屏左右滑动切换）。
4. **详情页操作**（非本人且非管理员仅能"收藏"）：
   - 心形图标收藏 / 取消收藏（幂等，描边↔实心切换）
   - 开放到广场 ↔ 转私有
   - 编辑信息（标题 / 分类）
   - **编辑文件**（重命名 · 删除 · 拖拽把手排序 / 上下移微调 · 追加上传），一次"保存"写回服务器
   - 删除（连带按引用计数清理磁盘 md5 文件与缩略图）
5. **多选批量操作**：顶栏点“选择”进入多选（仅“我的”可用的动作：合并 / 公开 / 私有 / 送人 / 删除）：
   - **合并**：选中 ≥ 2 个资源，归并为一个新资源（按列表顺序汇入 items，首个文件定封面，收藏关系一并迁回）。
   - **送人**：选一个接收用户后送出，资源立即转为**私有**并从你的“我的”列表消失；接收方登录后可在自己的“我的”里看到它。
   - 批量接口逐项执行不中断，部分失败会提示“成功 N，失败 M”；操作后就地修补列表卡片，不重新拉取。
6. **批量自动入库（可选）**：不想逐个点上传时，直接把文件或文件夹拷进工作目录的 `scan/`：
   - **散文件**：每个白名单文件（图片/视频）各自成为一个独立资源，标题 = 文件名去扩展名。
   - **一级文件夹**：夹内（不递归）的白名单文件收进同一个资源，标题 = 文件夹名，item 按文件名排序；空夹（无可用文件）跳过。
   - 服务每 10 秒扫描一轮；文件写入后需静置 ≥ 30 秒（mtime 稳定）才会被处理，避免拷到一半被误入库。
   - **去重**：内容与已入库资源重复（md5 命中）的文件会被移入 `scan/.duplicates/` 保留，不重复入库。
   - 入库后的源文件会被**移动**进 `store/`（同盘瞬间完成，`scan/` 不留原件）；归属管理员账号、默认私有，登录到"我的"视图刷新即可见，再按需开放到广场。
7. **管理员后台**：管理员可审核注册用户、停用账号、重置密码、开关注册、配置 IP 黑白名单。

## 🔧 命令行参数

```bash
xie-ms [options]

  --port <port>   服务监听端口（默认 3000）
  --dir <dir>     媒体库工作目录（默认当前目录；不存在会自动创建）
  -h, --help      显示帮助
  -V, --version   显示版本号
```

示例：

```bash
# 换端口
xie-ms --dir ~/MyMedia --port 8080

# 用当前目录作为媒体库
cd ~/MyMedia && xie-ms
```

## 📁 目录内会生成什么

在 `--dir` 指定的目录下，`xie-ms` 会自动创建以下结构：

```
<你的目录>/
├── upload_temp/    上传临时暂存（服务会自动清理，勿手动存放文件）
├── scan/           自动入库投递口（把文件/文件夹丢这里，服务每 10s 扫描一次并移走入库）
│   └── .duplicates/  扫描时发现内容重复（md5 命中）的文件被移到此处保留，不重复入库
├── store/          正式媒体文件，以 md5 命名（无扩展名），按 md5 前两位分子目录存放（<xx>/<md5>），相同内容自动去重
├── thumbnails/     视频缩略图（首次访问时懒生成，同样按前两位分片：<xx>/<md5>.jpg）
├── media.db        SQLite 数据库（元数据：collections / items / favorites，勿手动编辑）
└── users.json      用户与全局设置（包含 admin / 审核开关 / IP 名单等）
```

> 💡 整个目录可以整体拷贝 / 迁移；换台机器用同一个 `--dir` 启动，媒体库（含账号）即原样恢复。

## 🎞️ 支持的格式与大小

| 类型 | 允许扩展名 | 单文件大小 |
|------|-----------|-----------|
| 视频 | `mp4` `webm` `mov` `mkv` | 不限制 |
| 图片 | `jpg` `jpeg` `png` `webp` `gif` | 不限制 |

白名单以外的文件在上传阶段会被直接拒绝。一次上传可将图片与视频**任意混装**归为同一个资源，不再区分类型。

## ⚠️ 已知限制

当前版本属于 **MVP**（v0.4），以下能力尚未实现，使用前请确认能接受：

- **不支持转码 / 多清晰度 / HLS 切片**：视频以原始文件流式播放，依赖浏览器对容器的天然支持（实际建议 mp4/webm；mov/mkv 部分浏览器不可播）。
- **自动播放可能被浏览器拦截**：视频**不再默认静音**，而全视频资源首次打开会尝试自动播放；因带声音且非用户手势，浏览器很可能拦截，此时停在封面等用户手动点一下播放。
- **列表搜索为 JS 层过滤**：单次接口内部把候选行全部读入再按关键字过滤 + 分页；千量级资源下会变重。可未来改为 SQL `LIKE` + LIMIT。
- **并发首次访问同一视频的缩略图**：多个请求同时到达会重复跑 ffmpeg（产物一致、无副作用，但会浪费一时 CPU）。后续可进程内去重。
- **默认仅监听本机**：`--port` 不开局域网。想对外，请自行反向代理或修改启动参数。
- **mime 以扩展名为准**：不信任客户端上报的 Content-Type，避免上传时 mime 丢失导致内联播放失败。
- **字段有限**：除标题与分类外，不支持备注 / 描述 / 标签 / 多分类；如需可扩展。
- **送人无通知、不可回撤**：送出后资源属对方，对方不公开你就再也看不到（只能请对方再送回来）；也不做“只授读不交所有权”的共享权限模型。
- **自动入库（scan）为 MVP**：仅扫描 `scan/` **一级深度**（散文件与一级文件夹），嵌套子目录忽略；固定 10 秒轮询、无 CLI 开关与前端管理界面；入库进度只打印在服务控制台日志，不向前端推送；scan 资源一律归属管理员、默认私有、无分类。
- **不支持多目录**：一个实例 = 一个 `--dir`；想分个库就开多个实例、不同端口。
- **v0.3 → v0.4 破坏性变更**：取消资源分类，`collections` 删除 `kind` 列、`favorites` 删除 `target_type` 列，属**删列**且旧 `media.db` 不会自动迁移；请备份后删除 `media.db`（`users.json` 与 `store/` 无变化）让服务按新表重建并重新上传，或直接使用新目录。
- **v0.2 → v0.3 破坏性变更**：数据模型由 `videos/albums/album_items` 合并到 `collections/items`。
- **历史视频无元数据**：时长/分辨率是上传时用 ffprobe 读取的；在此之前入库的旧视频该字段为空，卡片/详情不显示对应角标，重新上传同内容文件即可自动补全（md5 去重不会占两份空间）。

## ❓ 常见问题

**启动报错 `未检测到 ffmpeg`？**
服务需要 ffmpeg 生成视频封面。请按[环境要求](#-环境要求)安装后重试。

**端口被占用？**
用 `--port` 换一个端口，例如 `xie-ms --dir ~/MyMedia --port 8080`。

**忘了管理员密码 / 打不开后台？**
用管理员账号在后台可改密；改密后该账号此前所有登录会立即失效，需重新登录。若无法登录，请联系部署本服务的管理员在用户数据中处理。

**别人能看到我上传的东西吗？**
默认不能。新上传内容仅自己可见，只有你手动"开放到广场"后，其他登录用户才会在广场看到。

**把资源送给别人后，我还能看到它吗？**
不能。“送人”会变更归属并强制转为私有，它从你的“我的”列表移除（你给它的收藏记录也会一并清除）；若只是不想自己留着，用“删除”更合适。

**能让局域网其他设备访问吗？**
默认监听本机。若需局域网访问，请用支持的方式暴露端口（如绑定 `0.0.0.0` / 反向代理 / 端口转发）；注意务必保留登录鉴权再对外。

**"编辑文件"点了没反应 / 保存按钮无效？**
先确认你对该资源有权限（本人或管理员）。追加文件后需要点"保存"才会写回服务器；未保存直接返回会丢弃本次修改。

## 🔒 安全说明

- 所有浏览、播放、上传、管理操作**均需登录**（未登录会 302 到 `/auth/login.html`）。
- 文件读取与修改会校验资源归属：私有内容只有上传者本人与管理员可访问；非本人无法删除 / 编辑。
- 管理员可在后台配置注册开关与 IP 黑白名单，进一步收紧访问。
- 本服务默认不开 HTTPS / 不提供验证码，**建议仅在可信局域网部署**，如需公网请搭反代 + HTTPS + 强密码。
